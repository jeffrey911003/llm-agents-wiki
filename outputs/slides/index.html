基本概念

一般 LLM 和 LLM Agent 差在哪？

一般 LLM

你問一句，它答一句，對話就結束。

像一位很博學、但只會坐著回答問題的顧問。

LLM Agent

  • 扮演一個角色
  • 感知環境
  • 採取行動
  • 隨時間學習、改變

定義：Agent 是身處環境中、會感知環境並對它採取行動、追求自己目標的系統（Franklin & Graesser 1997）。LLM Agent 就是用 LLM 當「大腦」的這種系統。

動機

為什麼光有 LLM 還不夠？

LLM 的基本功弱點

  • 精確算數
  • 查證事實
  • 不知道最新資訊
  • 不知道今天幾號

幻覺（hallucination）

很有自信地說出錯誤的內容。在 Agent 身上也會發生，而且會影響後續每一步行動。

解法方向：替 LLM 加上 記憶、規劃、工具、反思。接下來逐一介紹。

模組 ①

Profile：我是誰？

把角色寫進 prompt，例如基本資料、個性、和其他人的關係。

手寫

直接寫「你是一個外向的人」。

讓 LLM 生成

給規則和幾個範例，讓 LLM 大量產生角色。

從真實資料對齊

用真實的人口統計資料來設定角色。

例子：Generative Agents

每個角色都有一段手寫描述，例如職業和家人；描述裡的每一句都會變成這個角色的初始記憶。

模組 ②

Memory：記得什麼、想起什麼？

短期記憶

≈ LLM 的 context window，放得下的就是「現在記得的」。

長期記憶

≈ 外部資料庫，需要時再查出來。

想起哪段記憶 ＝ 多近（recency）＋ 多重要（importance）＋ 多相關（relevance）

重要性由 LLM 打 1–10 分（Generative Agents 的例子）：

模組 ③

Planning：怎麼拆解任務？

不看回饋

  • Chain-of-Thought：一步一步想
  • Tree of Thoughts：同時走多條路，再挑最好的

看回饋

做完一步，根據回饋調整計畫。回饋可以來自：

  • 環境
  • 人
  • 模型自己

階層規劃（Generative Agents）

一天的大綱
→ 每小時
→ 每 5–15 分鐘的行動
反例：沒有規劃的 Agent，會在 12 點、12:30、1 點各吃一次午餐。

經典做法 2 · Toolformer

Toolformer：自己學會用工具

插入 API 呼叫→執行→只留真的有幫助的

工具共 5 種：問答、Wikipedia 搜尋、計算機、行事曆、翻譯。

經典做法 3 · Reflexion

Reflexion：從失敗中學習

失敗→用文字寫下反省→存進記憶，再試一次

不用重新訓練模型，學到的東西存在記憶裡。

130/134ALFWorld 解出的題數
91.0%HumanEval 寫程式（GPT-4 為 80.1%）
但要有可靠的檢查：拿掉「自己寫測試」只留反省，準確率反而從 60% 掉到 52%。
